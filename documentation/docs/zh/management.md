# 后台管理

本章介绍如何在 Pinmok 后台管理内容。如果你已经熟悉 CMS 的基本概念，可以直接展开下方的「快速开始」浏览核心流程。

??? abstract "快速开始"

    内容管理后台包含三个模块：

    - **分类**：内容的组织维度，供模板按分类筛选和展示
    - **文章**：常规内容条目，必须归属于一个分类
    - **单页**：独立内容页面，不归属任何分类，通过唯一标识直接调用

    文章与单页共享相同的数据结构和编辑界面，区别仅在于单页没有分类字段。

    三者均支持多语言：共用字段（如分类、状态、封面图）在所有语言中保持一致；标题、正文等翻译内容按语言标签页分别填写。未翻译的语言自动回退到默认语言。

## 分类

分类是内容的组织维度。一篇"公司新闻"归属于"新闻"分类，一篇"产品手册"归属于"资料"分类。前端模板通过分类来筛选和展示内容，例如"只显示新闻分类下的最新
5 篇文章"。

**分类不是导航。** 导航是网站的菜单结构，由 Pinmok
的导航模块独立管理；分类是内容的属性，决定的是"这篇内容属于什么类型"。一个分类可以被多个导航项引用，也可以不被任何导航引用而仅用于模板筛选。

### 创建分类

进入后台 **内容管理 > 分类**，点击"添加"按钮：

![添加分类](assets/images/category_add.zh.png)

#### 基础信息

| 字段         | 说明                                                                                                             |
|--------------|------------------------------------------------------------------------------------------------------------------|
| **上级分类** | 如果启用层级，可在此选择父分类；默认为顶级分类                                                                   |
| **封面图片** | 分类的展示图片，可在模板中调用                                                                                   |
| **模板**     | 指定该分类在前端使用的渲染模板。遵循 Pinmok 模板规则：当存在多个可选模板时才会出现在下拉列表中，否则仅显示"默认" |
| **排序**     | 分类的排序权重，数值越小越靠前。获取分类列表或后台展示时均参与排序                                               |
| **是否启用** | 控制该分类是否有效。禁用后，该分类下的文章在前端不可见，但文章本身不会被删除                                     |

#### 多语言翻译

在"分类翻译"区域，从下拉列表中选择语言，输入对应的名称和描述。如需添加其他语言，点击「添加另一个 分类翻译」按钮，重复上述操作。

!!! tip "提示"

    并非所有翻译都必须填写。Content 获取内容时，如果找不到对应的语言翻译，会自动回退到默认语言。例如系统支持四种语言、默认语言为英语，若只填写了英语和中文，法语用户访问时将看到英语内容。

保存后，分类即可在文章编辑页中被选用。

## 文章

### 发布一篇文章

进入 **内容管理 > 文章**，点击"添加"按钮：

![添加文章](assets/images/article_add.zh.png)

#### 多语言正文区

| 字段       | 必填 | 说明                                                     |
|------------|------|----------------------------------------------------------|
| **语言**   | 是   | 首先填写默认语言的内容，其他语言可在保存后补充           |
| **标题**   | 是   | 文章的标题                                               |
| **副标题** | 否   | 通常与标题一起出现在文章头部                             |
| **摘要**   | 否   | 用于列表页展示时的简短描述                               |
| **内容**   | 否   | 文章正文，使用富文本编辑器，支持图文混排、表格、代码块等 |

#### 文章属性区

| 字段         | 必填 | 说明                                                                           |
|--------------|------|--------------------------------------------------------------------------------|
| **分类**     | 是   | 文章所属的分类，必须在创建文章前先完成分类的创建                               |
| **封面图片** | 否   | 用于列表页缩略图和社交媒体分享，支持裁切                                       |
| **模板**     | 否   | 指定该文章在前端使用的渲染模板，规则与分类模板相同                             |
| **排序**     | 否   | 文章排序权重，默认值为 `10000`。无论按何种方式获取文章列表，该排序码均参与排序 |
| **附加信息** | 否   | JSON 格式，供前端模板或开发者自定义使用                                        |
| **置顶**     | 否   | 标记后文章在列表中优先显示                                                     |
| **推荐**     | 否   | 标记为精选内容，供模板单独调用                                                 |

#### 文章资源区

可以为文章附加额外的资源文件（图片、多媒体、文档等），适用于相册、下载、或模板自定义展示等场景。

点击「添加另一个文章资源」增加一行：

![添加资源](assets/images/add_resource.zh.png)

- **放大镜图标**：弹出资源库窗口，从已有资源中选择文件
- **+ 图标**：弹出上传窗口，上传新文件至资源库
- 上传完成后需关闭窗口，重新点击放大镜图标选择刚上传的文件
- 点击"保存"后，选中的资源才会与文章关联

!!! tip "提示"

    资源上传后会统一进入 Pinmok 资源库。同一张图片多次上传时，系统基于 SHA-256 哈希自动去重，只保留一份物理文件。

填写完成后点击"保存"或"保存并继续编辑"，文章将以草稿状态保存。

### 状态与工作流

文章从创建到发布经历以下状态流转：

| 状态       | 说明                                         | 前端可见性 |
|------------|----------------------------------------------|------------|
| **草稿**   | 初始状态，内容尚未完成或待内部确认           | 不可见     |
| **待审核** | 内容已完成，提交审核，等待管理员确认         | 不可见     |
| **已退回** | 审核未通过，退回修改                         | 不可见     |
| **已发布** | 审核通过，已正式上线                         | 可见       |
| **已撤回** | 已发布的内容被主动下线，可重新编辑后再次发布 | 不可见     |

状态流转受权限控制：

- **普通编辑**：保存为草稿，或提交审核。提交后文章进入"待审核"状态，不可再编辑
- **审核人员**：对"待审核"文章执行"发布"或"退回"。退回的文章回到可编辑状态
- **已发布文章**：审核人员可执行"撤回"操作。撤回后文章回到可编辑状态

!!! note "注意"

    只有"草稿"和"已退回"状态的文章可以直接编辑。处于"待审核"和"已发布"状态的文章必须先变更状态（退回或撤回）后才能修改。

### 文章列表操作

在文章列表页，你可以：

![文章列表](assets/images/article_list.zh.png)

- **搜索**：按标题关键词快速查找
- **排序**：点击表头按创建时间、发布时间、排序码等排序
- **筛选**：按分类、状态、置顶/推荐标记过滤
- **批量操作**：勾选多篇内容后，可批量修改状态或删除

## 单页

### 单页与文章的区别

单页（Page）与文章共享同一套数据结构和编辑界面，但有两个核心区别：

- **无分类**：单页不需要也不显示分类字段
- **独立调用**：单页通过唯一的标识（Slug）被模板直接调用，不通过分类列表展示

### 适用场景

单页适合存放不归属于任何内容分类的独立页面，例如：

- 关于我们
- 联系方式
- 服务条款
- 帮助中心首页

### 创建单页

进入 **内容管理 > 单页**，操作方式与文章完全一致：填写标题、正文、设置状态、上传封面图等。唯一的不同是页面中没有"分类"字段。

单页同样支持多语言，切换语言标签页即可填写译文。

!!! note "注意"

    单页和文章在底层共用一个数据模型，系统通过内部标识区分二者。这个区分对使用者完全透明——需要分类的用"文章"，不需要分类的用"单页"。
