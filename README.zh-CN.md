## 简介

Pinmok Content 是基于 Pinmok 的内容管理 app，提供轻量的 CMS 能力。在后台编辑内容，通过主题模板在前端展示，通过内置标签灵活组织页面内容，开箱即用，也可以按需定制。

## 功能

**文章管理**
支持文章的创建、编辑与发布，可按分类组织，支持推荐、置顶等展示控制。

**页面管理**
与文章共用同一数据结构，适合承载独立的静态内容页面，无分类约束。

**分类系统**
为文章提供多级分类支持，便于内容归档与导航。

**前端展示**
内容展示与主题模板深度集成，后台可配置模板变量与组件，无需改动代码即可调整前端呈现。

**内置标签**
提供内置模板标签，在任意模板位置灵活调用文章列表、推荐内容、分类导航等数据。

## 依赖

- Pinmok >= 1.0（需先安装并配置 Pinmok 核心）
