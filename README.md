## Introduction

Pinmok Content is a lightweight CMS app built on Pinmok. Write and manage content in the admin, display it on the frontend through theme
templates, and organize page layouts flexibly with built-in template tags — ready to use as-is, or customizable as needed.

## Features

**Article management**
Create, edit, and publish articles. Organize by category, and control presentation with options like featured and pinned.

**Page management**
Shares the same data structure as articles, suited for standalone static content pages without category constraints.

**Category system**
Hierarchical categories for articles, supporting content organization and navigation.

**Frontend display**
Content rendering is integrated with the theme template system. Template variables and components are configurable from the admin — no code
changes needed to adjust how content appears on the frontend.

**Built-in tags**
Built-in template tags for pulling article lists, featured content, category navigation, and more into any template.

## Requirements

- Pinmok >= 1.0 (Pinmok core must be installed and configured first)
